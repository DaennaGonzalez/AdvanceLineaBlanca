# Advance Reparación de Línea Blanca

Landing estática lista para XAMPP, creada con HTML, CSS y JavaScript sin dependencias.

## Edición rápida

- Datos del negocio y `SITE_URL`: objeto `BUSINESS` al inicio de `script.js`; reemplazar también `https://example.com` en `index.html`, `robots.txt` y `sitemap.xml` al publicar.
- Marcas: arreglo `brands` en `script.js`. Por ahora todos los elementos utilizan `MABE.webp` como recurso temporal.
- Equipos, trabajos y preguntas frecuentes: arreglos `appliances`, `evidenceData` y `faq` en `script.js`.
- Vista local: iniciar Apache en XAMPP y abrir `http://localhost/PAGINAWEB_LINEABLANCA/`.
